# Authentication email assets

`unicon-logo-v1.png` is the immutable inline logo for authentication email
template protocol v1.

- Content ID: `unicon-logo-v1`
- Filename: `unicon-logo-v1.png`
- Content type: `image/png`
- SHA-256: `bf0c165ed6fa6f7ea8c9fb59e1625bcb00a817be3fb06871312765c7bcec87d5`

Changing its bytes requires a new template protocol and a new versioned asset
filename. The asset is packaged with the backend and must not be fetched from a
remote host or loaded from the database.
